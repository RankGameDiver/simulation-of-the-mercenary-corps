## 1. 화면이 답해야 할 질문

육성 화면은 한 턴마다 다음 세 질문에 바로 답할 수 있어야 한다.

1. **지금 상태는?** — 기력, 능력치, 자원, 전적
2. **이번 턴에 뭘 할 수 있고, 하면 어떻게 되나?** — 일과별 비용·효과·불가 사유, 실행 전 예상 변화
3. **다음 목표는?** — 다음 숙련 레벨까지 남은 경험치, 다음에 해금될 스킬·운용

용병이 한 명뿐이므로 목록·선택 단계 없이 **모든 정보가 한 화면에 항상 펼쳐져 있는** 구조로 간다 [확정: 2.1].

## 3. 영역별 상세

### 3.1 ① 상단 바
| 요소 | 내용 |
|---|---|
| 턴·단계 | `12턴 · 계획 단계` / `실행 중…` / `정산` — 지금의 `turnNumberText` + `turnPhaseText`를 한 줄로 합친다 |
| 자원 | 골드 · 보급 · 영향력 (아이콘 + 숫자). 기존 `ResourceBar` 재사용 |
| 자원 변화 | 정산 시 변화량을 숫자 옆에 `+50` / `-5`로 잠깐 띄운다 |
| 메뉴 `[≡]` | 사망 기록 열람, 설정(3.6), 타이틀로 |

### 3.2 ② 용병 상태 (좌)
위에서 아래로 **정체성 → 소모 자원 → 능력치 → 무장** 순서.

| 블록 | 내용 | 비고 |
|---|---|---|
| 정체성 | 초상(자리만), 이름, 전적(승/패), 생존 턴 | 전적·생존 턴은 `IMercenary`에 추가 필요([미구현 목록](미구현_목록.md) 3장) |
| 기력 | 0–100 게이지 + 숫자 + 상태 라벨(지침/매우 지침/극심한 피로) | 라벨 구간은 지금 `GetStaminaLabel` 유지. 구간별로 게이지 색 변경 |
| HP | `현재 / 최대(건강 × 10)` 게이지 | **전투 후에도 HP가 다음 전투까지 이어진다** [확정]. 그래서 육성 화면에서도 현재 HP를 항상 보여준다. 최대치의 30% 이하면 게이지를 빨간색으로 [제안] |
| 능력치 | 5종을 1–10 막대 + 숫자로 | 막대 10칸이라 한눈에 비교 가능. 마우스를 올리면 용도 툴팁(기획서 2.2 표 문구) |
| 무장 | 무기 이름(계열), 운용 | 상세는 ④ 장비 탭 |

- 이 영역은 **조작이 없는 읽기 전용**이다(`MercenaryStatusPanel`). 일과 선택은 ③에서만 한다.

### 3.3 ③ 일과 선택 (중앙)

**일과 카드** — `ActionCatalog`의 일과마다 카드 1장 [확정: 일과는 `ActionDefinition`·`ActionCatalog`로 정의]. 4장이면 2×2, 늘어나면 가로 스크롤 그리드.

카드 한 장의 구성:
```
┌────────────────┐
│ 훈련        [1]│  ← 이름 + 단축키
│ 기력 -15       │  ← 비용 (부족하면 빨간색)
│ 숙련 경험치    │  ← 효과 요약 한두 줄
│ 스킬 습득 확률 │
└────────────────┘
```

카드 상태:
| 상태 | 표시 | 조건 |
|---|---|---|
| 선택 가능 | 기본 | — |
| 선택됨 | 테두리 강조 + 체크 | 이번 턴 지정된 일과(`CurrentAction`) |
| 조건 불충분 | 회색 + 하단에 **불가 사유** (`기력 부족: 40 필요`) | 기력·보급 부족 등 |
| 미해금 | 회색 + 자물쇠, 또는 숨김 | `IsActionUnlocked == false`. 숨길지는 `hideWhenLocked` [확정] |

- "조건 불충분"과 "미해금"을 구분한다. 플레이어가 **무엇을 하면 풀리는지** 알 수 있도록 조건 불충분 카드에는 반드시 사유를 적는다.

**일과별 추가 선택**
| 일과 | 카드를 누르면 |
|---|---|
| 훈련 | 카드 아래에 **훈련 대상 선택줄**이 펼쳐진다: `[검술] [창술] [둔기술] [방패술]` (각 버튼에 현재 레벨 표시). 대상을 골라야 실행 가능 [제안: 기획서 6.3 훈련 대상 선택]. 스킬을 지정해 훈련할 수 있게 되면 스킬도 대상에 들어간다 [미정: PROF-3] |
| 휴식 | 바로 선택됨 |
| 연습전 | 바로 선택됨 |
| 출전 | 선택됨 + 카드에 경고 문구 상시 표시. **[턴 넘기기]를 누를 때** 확인 창: `패배하면 카엘은 사망합니다. 현재 HP 64 / 100. 출전하시겠습니까?` [확정: 실전 패배 = 사망]. HP가 이어지므로 확인 창에 현재 HP를 함께 보여준다 [제안]. HP가 낮을 때 출전을 막을지 경고만 할지는 [미정: HP-3] |

- **전투 전에는 상대 정보를 아무것도 보여주지 않는다** [확정]. 연습전·출전 카드, 확인 창, 예상 변화 어디에도 상대의 이름·무기·능력치를 표시하지 않는다. 카드와 확인 창에 보이는 것은 내 용병의 정보뿐이다.

**예상 변화 미리보기** — 선택한 일과의 결과를 실행 전에 보여준다.
```
예상 변화
기력 72 → 57  ·  검술 경험치 +40 (340 → 380 / 500)  ·  스킬 습득 확률 10%
```
- 확률 요소는 확률로, 확정 요소는 숫자로 보여준다. 전투(연습전·출전)는 `승리 시 기력 -N`만 표시한다.
- 이를 위해 `ActionDefinition`에 **비용·효과 수치 필드**가 필요하다. 지금은 `displayName` / `description`만 있다 → 6장 "데이터·로직" 참고.

**[턴 넘기기] 버튼** — 지금의 "턴 종료" 버튼을 대체한다(`TurnManager.EndPlanningPhase()` 호출은 그대로).
- **일과는 플레이어가 직접 고른다** [확정]. 카드를 눌러도 일과는 *지정*만 되고, **[턴 넘기기]를 눌러야 실행된다** [확정]. 턴을 넘기기 전에는 다른 카드를 눌러 몇 번이든 바꿀 수 있다.
- 일과를 고르지 않았으면 버튼은 비활성이고 `일과를 선택하세요`를 표시한다 [확정]. 자동 휴식 같은 기본 행동은 없다.
- 훈련은 훈련 대상까지 골라야 버튼이 활성화된다.
- 실행 중에는 비활성(지금 동작 유지)

### 3.4 ④ 성장 정보 (우, 탭 3개)

**[숙련] 탭** (기본 탭)
- 계열 숙련 4종: 이름, 레벨, 경험치 막대(`현재 / 다음 레벨`) [확정: 계열 숙련 4종 고정]
- 장착 무기의 지배 숙련은 강조 표시(공격으로 오르는 숙련이라는 것을 알려줌)
- **다음 해금**: 숙련 레벨 조건으로 열리는 스킬·운용(Lv3 양손, Lv5 필살기)을 가까운 순서로 2–3개

**[스킬] 탭**
```
장착 (3/3)
[ 연속 베기 Lv.2 ] [ 방패 밀치기 Lv.1 ] [ 비어 있음 ]

보유 스킬
· 연속 베기      검술   Lv.2   쿨 2턴   (장착 중)
· 방패 밀치기    방패술 Lv.1   쿨 3턴   (장착 중)
· 찌르기 견제    창술   Lv.1   쿨 2턴   [장착]
```
- 슬롯 3칸 [제안: 기획서 5.5]. 장착은 **클릭과 드래그를 둘 다 지원한다** [확정].

| 조작 | 클릭 | 드래그 |
|---|---|---|
| 장착 | 보유 목록의 `[장착]` → 빈 칸에 들어감. 칸이 다 찼으면 슬롯이 깜빡이고, 교체할 슬롯을 클릭 | 보유 목록의 스킬을 슬롯에 놓음. 찬 슬롯에 놓으면 교체 |
| 해제 | 슬롯 선택 후 `[해제]` (또는 슬롯 우클릭) | 슬롯의 스킬을 슬롯 영역 밖에 놓음 |
| 순서 변경 | 슬롯 A 클릭 → 슬롯 B 클릭으로 맞바꿈 | 슬롯을 다른 슬롯에 놓아 맞바꿈 |

- 드래그 중에는 놓을 수 있는 슬롯을 강조하고, 놓을 수 없는 곳(목록 위 등)에서는 원위치로 돌아간다. 클릭으로 교체 대기 중일 때 `Esc`나 빈 곳 클릭으로 취소한다.
- 두 방식 모두 같은 장착 명령(예: `EquipSkill(skill, slotIndex)`)을 호출해서 결과가 같도록 한다.
- 장착 변경은 육성 화면 계획 단계에서만 가능 [제안: 기획서 5.5]. 턴을 소모하지 않는다.
- 스킬 숙련 레벨을 함께 보여준다 [확정: 스킬별 숙련].

**[장비] 탭**
- 무기: 이름, 계열, 기본 공격력, 운용(한손 단독/한손+방패/양손)과 운용 효과
- 상성 고리 도식: `창 > 검 > 둔기 > 창`, 내 무기 계열 강조
- 무기 교체·구매 기능이 생기면 이 탭에 붙인다(지금은 열람만)

### 3.5 ⑤ 로그 (하단)
- 접힌 상태에서는 **최근 한 줄**만, 펼치면 기존 `ActionLogPanel` 스크롤 목록.
- 토글 키는 지금처럼 `KeyboardInputManager`의 패널 바인딩을 쓴다.
- **매 턴 결과 요약 로그 한 줄을 남긴다** [확정]. 결과 팝업을 띄우든 안 띄우든 항상 남긴다. 형식 [제안]:
  ```
  12턴 · 훈련(검술) — 기력 72→57, 검술 +40
  13턴 · 휴식 — 기력 57→87, 보급 -5
  14턴 · 연습전 승리 — HP 87→52, 기력 -10, 검술 +25
  15턴 · 훈련(방패술) — 기력 87→72, 방패술 +40, ★ 스킬 습득: 방패 밀치기
  ```
- 레벨 업·스킬 습득처럼 중요한 변화는 `★` 표시와 강조색으로 구분한다.

### 3.6 설정 창
메뉴 `[≡]` → 설정에서 연다. 메인 화면의 설정 창(기획서 11.1)과 같은 창이며, 메인 화면 쪽은 구현되어 있다(`SettingsPanel`). 옵션은 `◀ 값 ▶` 좌우 선택으로 고르고, 바꾸면 바로 적용·저장된다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 화면 모드 | 실행 시 상태 | 창 모드 / 전체 화면(테두리 없는 창) |
| 해상도 | 실행 시 상태 | 모니터가 지원하는 해상도 목록(주사율 무시) |
| 턴 결과 팝업 생략 | 꺼짐 | **켜면 결과 팝업을 띄우지 않고 요약 로그만 남긴다** [확정] |

- 설정값은 세이브 데이터가 아니라 기기 설정으로 저장한다(`PlayerPrefs`) [제안]. 용병이 죽고 새로 시작해도 유지된다.
- 옵션을 켜면 팝업이 나오지 않는 대신 접힌 로그의 최근 한 줄이 잠깐 강조되어, 이번 턴 결과가 나왔다는 것을 알 수 있게 한다 [제안].

## 4. 턴 흐름에 따른 화면 변화

```
[계획] ──턴 넘기기──▶ [실행] ──▶ 요약 로그 기록 ──▶ [결과 팝업]* ──확인──▶ [정산] ──▶ [계획]
                        │
                        └─ 연습전·출전 ─▶ [전투 화면] ─┬─ 승리·연습전 패배 ─▶ 요약 로그 ─▶ [결과 팝업]* ─▶ [정산]
                                                       └─ 실전 패배 ─▶ [사망 화면] ─▶ 캐릭터 생성

* "턴 결과 팝업 생략" 옵션이 켜져 있으면 건너뛰고 바로 정산으로 간다.
```

| 단계 | 화면 |
|---|---|
| 계획 | 모든 조작 가능. 일과를 고를 때까지 [턴 넘기기] 비활성 |
| 실행 | 일과 카드·[턴 넘기기]·스킬 장착 비활성. 상단 바 `실행 중…` |
| 요약 로그 | 실행 결과를 한 줄로 로그에 남긴다(3.5). 매 턴 항상 [확정] |
| 결과 팝업 | **매 턴 띄운다** [확정]. 화면 중앙에 이번 턴 변화: `기력 72 → 57`, `HP 87 → 52`, `검술 +40`, 레벨 업·**스킬 습득**은 크게 강조. 확인(`Space`/`Enter`/클릭)을 눌러야 정산으로 넘어간다. 설정에서 생략 가능(3.6) |
| 정산 | 자원 변화량 표시, 턴 번호 증가 후 계획으로 |
| 전투 화면 | 전환 방식(같은 씬 패널 교체 / 별도 씬)은 **전투 구현을 시작할 때 정한다** [확정] → [미정: BATTLE-4] |
| 사망 화면 | 용병 이름, 생존 턴, 전적, 마지막 상대. `기록 보기` / `새 용병 만들기` [확정: 7장]. 마지막 상대는 사망 후 기록이므로 공개해도 "전투 전 비공개" 원칙에 어긋나지 않는다 |

## 5. 조작

| 입력 | 동작 |
|---|---|
| `1`–`4` | 일과 카드 선택 (카탈로그 순서) |
| `Q` `W` `E` `R` | 훈련 대상 선택(검술·창술·둔기술·방패술) — 훈련을 골랐을 때만 |
| `Space` / `Enter` | 턴 넘기기 / 결과 팝업 닫기 |
| `Tab` | ④ 탭 전환 |
| `` ` `` | 로그 펼치기/접기 (지금 바인딩 유지) |
| `Esc` | 확인 창 닫기 / 스킬 교체 대기 취소 / 메뉴 |

- 키 입력은 모두 `KeyboardInputManager`에 모은다(각 패널이 직접 키를 읽지 않는다는 현재 규칙 유지).
- 마우스로도 모든 조작이 가능해야 한다. 키보드는 보조.

## 6. 구현 설계

화면을 구성하는 클래스·데이터·이벤트의 설계다. 무엇이 남았고 어떤 순서로 만들지는 [미구현 목록](미구현_목록.md) 9장에 있다.

### 패널·컴포넌트 (패널은 `PanelBase` 상속)
| 클래스 | 영역 | 필요한 데이터 | 상태 |
|---|---|---|---|
| `UIManager` | ① 턴·단계 표시, [턴 넘기기] 버튼 | `GameEvents` 턴·용병 이벤트 | 구현됨 |
| `ResourceBar` | ① 자원 3종 | `OnResourcesChanged` | 값 하드코딩, 이벤트 구독 전환 필요 |
| `MercenaryStatusPanel` | ② 용병 상태(읽기 전용) | `IMercenary` | 구현됨(전적·생존 턴 제외) |
| `RoutinePanel` | ③ 일과 카드·훈련 대상·미리보기 | `ActionCatalog`, `IMercenary` | 카드·선택만 구현 |
| `RoutineCard` | ③ 카드 한 장(프리팹) | `ActionDefinition`, 선택 가능 여부·사유 | 해금/선택 상태만 구현 |
| `GrowthPanel` | ④ 탭 전환 틀과 임시 내용 | `WeaponLoadout` | 구현됨. 탭 내용은 아래 뷰로 교체 예정 |
| `ProficiencyView` / `SkillLoadoutView` / `EquipmentView` | ④ 각 탭 | 숙련 경험치, 보유·장착 스킬, `WeaponLoadout` | 미구현 |
| `SkillSlot` / `SkillListItem` | ④ 스킬 탭의 슬롯·목록 항목. 클릭은 `IPointerClickHandler`, 드래그는 `IBeginDragHandler`·`IDragHandler`·`IEndDragHandler`·`IDropHandler`로 처리하고, 둘 다 같은 장착 명령을 호출 | 스킬 정의, 슬롯 번호 | 미구현 |
| `ActionLogPanel` | ⑤ 로그(접힘 시 최근 한 줄) | `GameEvents.OnLogMessage` | 구현됨 |
| `TurnResultPopup` | 결과 팝업. 설정이 "생략"이면 열리지 않는다 | `TurnResult` | 미구현 |
| `ConfirmDialog` | 출전 확인 등 공용 확인 창 | — | 미구현 |
| `SettingsPanel` | 3.6 설정 창 | `GameSettings` | 미구현 |

### 데이터·로직
| 대상 | 역할 |
|---|---|
| `ActionDefinition` 수치 필드 | 카드·미리보기용: 기력 변화량, 보급·골드 비용, 필요 기력, 효과 요약 문구. 단축키 순서는 `ActionCatalog` 순서를 따른다 |
| `TurnResult` | 한 턴의 변화량 목록(기력·HP·자원·숙련 경험치·레벨 업·스킬 습득). 팝업과 요약 로그가 **같은 데이터**를 쓴다 |
| `TurnResultFormatter` | `TurnResult` → 요약 로그 한 줄 문자열. 순수 함수라 EditMode 테스트 대상 |
| `GameSettings` | 설정값 보관·저장(`PlayerPrefs`). 지금은 `SkipTurnResultPopup` 하나 |

- 요약 로그는 팝업 여부와 무관하게 `OnTurnResolved`를 받은 쪽(로그 기록기)이 `GameEvents.Log`로 남기고, 팝업은 같은 이벤트를 받아 `GameSettings`를 보고 열지 말지 정한다. 두 경로를 분리해 두면 옵션이 로그에 영향을 주지 않는다.
- 팝업이 열려 있는 동안 정산 진행을 멈춰야 하므로, `TurnManager`의 정산 대기를 "팝업이 닫힐 때까지"로 바꾼다. 이벤트로 `OnTurnResultAcknowledged`를 받아 진행한다(팝업 생략 시에는 즉시 발행).
- 전투 시작 시 `Combatant`는 `IMercenary.CurrentHp`로 시작하고, 끝나면 남은 HP를 용병에 되돌려 쓴다.

### 필요한 이벤트 (`GameEvents`에 추가)
| 이벤트 | 발행 | 구독 |
|---|---|---|
| `OnResourcesChanged(골드, 보급, 영향력)` | 자원 관리자 | `ResourceBar` |
| `OnTurnResolved(TurnResult)` | 일과 실행 로직(전투 일과는 전투 종료 후) | 요약 로그 기록기, `TurnResultPopup` |
| `OnTurnResultAcknowledged()` | `TurnResultPopup`(닫힘) 또는 팝업 생략 시 즉시 | `TurnManager`(정산 진행) |
| `OnSkillAcquired(스킬)` | 훈련·숙련 레벨업 | 결과 팝업, 스킬 탭 |
| `OnProficiencyChanged(계열, 레벨, 경험치)` | 숙련 시스템 | 숙련 탭 |

## 7. 결정 사항 (v0.2)

| 항목 | 결정 |
|---|---|
| 일과 실행 | 일과는 직접 고르고, **[턴 넘기기]를 눌러야만** 실행된다. 미선택이면 턴을 넘길 수 없다 |
| HP | 전투 후에도 **다음 전투까지 이어진다** |
| 스킬 장착 | **클릭과 드래그 둘 다** 지원 |
| 전투 화면 전환 | **전투 구현을 시작할 때** 정한다 |
| 전투 전 상대 정보 | **아무것도 보여주지 않는다** |
| 결과 팝업 | **매 턴** 띄우고, 동시에 **요약 로그**를 남긴다. 설정의 "턴 결과 팝업 생략"을 켜면 요약 로그만 남는다 |

- 이 결정으로 새로 생긴 결정 필요 사항(HP 회복 수단, 연습전 패배 후 HP, 낮은 HP 출전 제약, 최대 HP 증가 시 현재 HP)은 [미정사항.md](미정사항.md)의 HP-1~4로 옮겼다.
