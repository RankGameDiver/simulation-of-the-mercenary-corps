## 9. 육성 화면 UI (남은 단계)

UI 설계는 [UI_육성화면.md](UI_육성화면.md) 3–6장에 있다. 단계마다 위 시스템 작업이 먼저 필요하다.

**2단계 — `ActionDefinition` 수치 필드 추가 후** (1·2장 선행)
- 일과 카드 비용 표시(부족하면 빨간색), 조건 불충분 상태와 불가 사유
- 예상 변화 미리보기(`RoutinePanel.selectionText` 자리에 표시)
- `TurnResultPopup` 결과 팝업, 요약 로그 형식 적용
- 메뉴 `[≡]`(사망 기록·설정·타이틀), `SettingsPanel`과 `GameSettings`(`PlayerPrefs`, 팝업 생략 옵션)
- 팝업 생략 시 접힌 로그 한 줄 강조

**3단계 — 숙련 경험치·스킬 시스템 구현 후** (4·5장 선행)
- 숙련 탭 경험치 막대(`현재 / 다음 레벨`)
- 스킬 탭: 장착 슬롯·보유 목록, 클릭과 드래그 장착(`SkillSlot`·`SkillListItem`)
- 훈련 대상 선택줄과 `Q` `W` `E` `R` 단축키
- 레벨 업·스킬 습득 `★` 강조

**4단계 — 전투·사망 흐름 구현 후** (6–8장 선행)
- 출전 확인 창(`ConfirmDialog`, 현재 HP 표시)
- 전투 화면 전환(BATTLE-4)과 전투 UI: 행동 버튼 4개, 스킬 하위 목록, 양측 HP, 전투 로그
- 사망 화면
